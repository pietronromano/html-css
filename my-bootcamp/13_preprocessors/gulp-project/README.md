# Gulp Project

References:
- [Gulp Official Documentation](https://gulpjs.com/docs/en/getting-started/quick-start)

## Usage


1.	Recreate node_modules folder by running
```bash
cd my-bootcamp/13_preprocessors/gulp-project
npm install
```


2.	Install Gulp and its plugins.
```bash
npm install -g gulp-cli
npm install --save-dev gulp
npm install --save-dev gulp-clean-css browser-sync
```


3.	Run Gulp.
After setting everything up, in your Terminal, run the default Gulp task to start the minification process and enable live reloading:
```bash
gulp
```
