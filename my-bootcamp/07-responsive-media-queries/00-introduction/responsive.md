## Responsive design:
  - is about creating web pages that look good on all devices!
  - is mandatory in today's world with the variety of devices available
  - Site used to have a desktop version and a mobile version: this was hard to maintain
    - Chrome DevTools can simulate different devices
  - Now we use a single codebase that adapts to different screen sizes
    - On mobile devices, content usually stacks vertically
    - On larger screens, content can be arranged in multiple columns
  - SEO benefits: Google ranks mobile-friendly sites higher in search results
